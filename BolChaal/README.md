# BolChaal

BolChaal is a planned voice-based English-speaking practice app.

## Repository layout
- `apps/mobile/`: Expo / React Native app using Expo Router
- `backend/`: FastAPI backend
- `web/`: landing page, privacy policy, and terms
- `marketing/`: store listing and marketing assets
- `docs/`: architecture, privacy, cost model, and launch checklist
- `.github/workflows/`: CI, Android build, and backend deployment workflows

## Important
This archive is a **project structure scaffold**. Placeholder source files and workflow files need implementation and configuration before the app can run or be published. Do not add real secrets to the repository.
